# Counterfactual Pulse 200초 결과

## 상태

`SKIPPED_NO_CANDIDATE`.

200초 full-fight는 `PROMOTE_CANDIDATE + scale 선택 + 장시간 학습 + held-out 통과` 이후에만 실행하는 단계다. Counterfactual pulse signal이 Phase 2에서 실패했으므로 이 조건을 하나도 충족하지 못했고, 200초 실행으로 우연한 좋은 episode를 찾지 않았다.

따라서 phase별 Damage, Damage received, differential, win/loss/tie, latency, proxy Target 200초 값은 자료 없음이다. 이를 0이나 성공으로 표기하지 않는다.
