### 정책 검토

18-pair development 평균은 조준 지표가 소폭 좋아졌지만 exact crossing-left에서 target 파괴 임계치를 놓쳐 Damage와 종료조건이 악화됐다. 따라서 평균 reward나 평균 Damage를 근거로 final bundle을 승격하지 않는다.

### Checkpoint 선택

pilot final 1434는 `ROLLBACK`이다. 1200은 exact crossing-left 종료를 보존했지만 mixed seed에서 action saturation이 25.06%였고 일부 종료 임계치 효과가 커 정책 성능 승격은 아니다. native checkpoint 1200은 장시간 seed 2101을 복구 가능하게 이어가기 위한 시작점으로만 동결한다.

### 첫 복구 실행 실패와 수정

첫 seed 2101 실행은 learner step 0에서 RLlib/pyarrow가 상대 checkpoint 경로를 URI로 해석하지 못해 중단됐다. 오류는 `ArrowInvalid: URI has empty scheme`이며 simulator/DLL 또는 policy 실패가 아니다. `train_rllib.py`가 존재 확인 후 checkpoint 경로를 절대 경로로 변환하도록 수정했고 단위 테스트 10개를 통과했다. 실패 stdout/stderr를 보존하기 위해 재실행 output tag와 process log에 `_r1`을 붙인다.
