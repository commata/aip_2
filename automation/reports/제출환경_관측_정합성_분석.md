# 제출 환경 관측·추론 경로 사전 감사

## 감사 범위

- `run_unreal_inference.py`
- `src/dogfight/unreal/policies.py`
- `src/dogfight/unreal/protocol.py`
- `src/dogfight/ai/hybrid_action_provider.py`
- `src/dogfight/ai/rllib_utils.py`
- `src/dogfight/envs/observation.py`
- `src/dogfight/envs/single_agent_env.py`

## 확인된 사실

### 1. 제출 Hybrid Provider가 학습·평가와 다르다

`run_unreal_inference.py`의 hybrid 경로는 legacy `HybridActionProvider`를 생성한다. 학습은 `ResidualTrainingActionProvider`, 조준 paired 평가는 `ResidualInferenceActionProvider`를 사용한다. legacy provider는 throttle blend와 별도 offensive residual 의미를 가지므로 현재 제출 경로는 학습 의미와 동일하지 않다.

### 2. BT가 매 server frame 실행되지 않는다

`ProviderCommandPolicy`는 `action_repeat` 동안 최종 action 전체를 cache한다. 따라서 repeat가 6이면 BT command도 6개 pair 동안 고정된다. 요구 계약은 BT 매 frame, RL residual만 configured repeat로 hold하는 구조다.

### 3. Tactical16 WEZ가 제출에서 항상 false다

학습 환경은 Tactical16 생성 시 `self._wez`를 전달한다. 제출 `ProviderCommandPolicy._build_observation()`은 WEZ config를 전달하지 않아 feature 15번 `in_wez`가 항상 `-1`이 된다.

### 4. health 의미가 학습과 제출에서 다르다

PlaneInfo에는 health가 없다. 제출 변환은 ownship/target health를 `1.0`으로 고정하지만 학습 환경은 simulator health를 그대로 사용한다. 첫 제출 가능 Tactical16 계약에서는 양쪽 모두 `health_source: unavailable_constant_one`으로 고정해야 한다.

### 5. phase 시간이 제출 ActionContext에 없다

Aim gate는 `sim_time_s`로 100/150초 phase를 선택한다. 제출 context에는 frame index만 있고 `sim_time_s`가 없어 Phase 1로 고정될 수 있다.

### 6. observation mode가 bundle과 독립된 CLI 기본값이다

CLI 기본은 `tactical16`이고 `auto`가 없다. 10D bundle을 Tactical16로 실행하거나 그 반대인 경우 의미·shape 불일치를 join 전에 명확히 차단하지 못한다.

### 7. residual surface/throttle 구현 자체는 재사용 가능하다

`ResidualInferenceActionProvider`는 residual scale을 `0.10/0.125/0.15`로 제한하고 saturation-aware composition을 지원한다. Gate OFF에서는 residual inference를 호출하지 않고 BT action을 그대로 반환하며, Gate ON에서도 final throttle을 BT throttle로 강제한다.

## 추가 확인이 필요한 의미

- Unreal velocity magnitude는 현재 `StateIndex.KCAS`에 그대로 저장된다. 이름은 KCAS지만 실제 packet 단위가 m/s라면 학습 simulator의 동일 index 단위와 다를 수 있다.
- Tactical16 altitude는 Unreal Z-up 값을 사용한다. NED D 변환과 함께 synthetic parity로 검증해야 한다.
- GeometryInfo signed Aspect Angle은 hard rear gate에 사용하지 않고 검증된 unsigned target ATA를 사용한다.

## 수정 후 동적 재검증

- 제출 Hybrid는 `ResidualInferenceActionProvider`만 사용하며 legacy provider 요청은 join 전에 실패한다.
- BT는 매 frame 실행하고 RL residual만 provider 내부 action repeat로 유지한다.
- Tactical16 health는 학습·제출 모두 `unavailable_constant_one` 계약을 선택할 수 있다.
- WEZ·phase는 공통 함수와 60Hz match 경과 시간으로 계산한다.
- bundle metadata와 config의 mode·size·계약·normalization·WEZ·health 불일치는 fail-fast 한다.
- RL 예외·NaN/Inf·166.7ms 초과 추론은 해당 frame에 정확한 BT action으로 복귀한다.
- 전체 회귀는 `automation/tests 114 passed, 14 subtests passed`, `tests 9 passed`다.

## 현재 판단

제출 경로의 코드·synthetic packet·localhost UDP 계약은 `SUBMISSION_PARITY_CONFIRMED`다. 다만 이는 아직 선택되지 않은 Tactical16 실제 bundle과 외부 서버까지 검증했다는 뜻이 아니다. 실제 packet 속도 단위와 최종 bundle 동적 추론은 각각 `NEED_MORE_EVIDENCE`, 실제 서버는 `SERVER_BLOCKED`로 남긴다.

## 자기 반박

localhost loopback은 synthetic provider를 사용했다. 실제 0815 DLL과 아직 없는 Tactical16 bundle의 파일 로딩·추론 지연이 synthetic provider와 다를 수 있으므로, 후보 동결 후 같은 검증을 다시 실행해야 한다.
