# Hybrid 200초 전체전 결과

`PROMOTE_CANDIDATE + scale 선택 + 장시간 학습 + held-out revalidation` 선행 조건을 충족하지 않아 200초 전체전을 실행하지 않았다. PPO iteration 15의 세 seed 평균 양수만으로는 pooled positive 8/16, 오염 2건, 최악 geometry Δ -0.003960을 상쇄할 수 없으므로 full-fight 후보로 과장하지 않는다.

실행 조건이 충족되면 Pure 0815 BT 및 정상 proxy target별 Damage dealt/received/differential, win/loss/tie, first Damage, Phase 1/2/3 Damage, Cone, minimum altitude, crash, Shot-Window 통계, RL inference/fallback/latency를 기록한다.

실제 server IP/port/team/scenario 정보가 없고 최종 Target으로 식별 가능한 새 DLL/XML pair도 발견되지 않았다. localhost 성능을 실제 서버 결과로 표현하지 않는다.

현재 상태: `NOT_PROMOTED / TARGET_BT_PENDING / SERVER_BLOCKED`.
