# Hybrid 200초 전체전 결과

현재 `PROMOTE_CANDIDATE + scale 선택 + 장시간 학습 + held-out revalidation` 조건을 아직 충족하지 않아 200초 전체전을 실행하지 않았다. short suite의 우연한 개선을 full-fight 후보로 과장하지 않는다.

실행 조건이 충족되면 Pure 0815 BT 및 정상 proxy target별 Damage dealt/received/differential, win/loss/tie, first Damage, Phase 1/2/3 Damage, Cone, minimum altitude, crash, Shot-Window 통계, RL inference/fallback/latency를 기록한다.

현재 상태: `NOT_PROMOTED / TARGET_BT_PENDING / SERVER_BLOCKED`.
