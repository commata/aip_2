# 하이브리드 Gate 선택성 검증

## 연구 질문

Gate A(phase-aware Aim), Gate B(Offensive), Gate C(Aim AND Offensive)가 실제 residual을 적용하기 전에 어떤 기하를 선택하는지, 그리고 frozen H7 10D policy를 적용했을 때 Pure 0815를 어떻게 바꾸는지 분리했다.

Gate threshold, reward, policy weights, residual scale 0.125, saturation-aware composition, action repeat 6은 고정했다. Gate만 바꿨다.

## Shadow 결과 — 30초 근접 geometry

18개 Pure BT trajectory에서 final action을 바꾸지 않고 판정만 재생했다.

| Gate | Active ratio | Episode median | Entry/Exit | Damage 3초 선행 포착 | 활성 구간 BT Roll/Pitch/Yaw 포화 |
|---|---:|---:|---:|---:|---:|
| A Aim | 17.37% | 15.25% | 29/29 | 6/6 | 77.64% / 11.29% / 71.14% |
| B Offensive | 39.08% | 34.27% | 18/18 | 6/6 | 71.31% / 30.21% / 56.50% |
| C Combined | 15.02% | 15.25% | 21/21 | 6/6 | 74.48% / 8.24% / 70.10% |

Gate C는 근접 geometry에서 Damage coverage를 잃지 않으면서 가장 좁았다. 그러나 active window에 BT roll/yaw가 이미 70% 이상 포화되어 있어 선택성만으로 control authority가 충분하다고 볼 수 없다.

## Shadow 결과 — 200초 proxy full-fight

0815/AIP2/AIP3 default 3회와 offensive-tail/crossing 좌우 9회, 총 12개 Pure BT full-fight를 합쳤다.

| Gate | Active ratio | Episode median | Entry/Exit | Damage 3초 선행 포착 |
|---|---:|---:|---:|---:|
| A Aim | 3.15% | 2.85% | 23/23 | 6/6 |
| B Offensive | 0.00% | 0.00% | 0/0 | 0/6 |
| C Combined | 0.00% | 0.00% | 0/0 | 0/6 |

Gate A의 3.15%는 전체 교전 engineering target 5~35%보다 조금 낮지만 0%는 아니며, 실제 Damage 직전 구간은 모두 포착했다. 반면 현 Gate B threshold는 proxy full-fight에서 한 번도 켜지지 않았다. 따라서 Gate C도 항상 꺼졌다.

default full-fight의 Damage event는 ATA 0.99~1.99°, target ATA 17~23°, closing 346~366m/s에 집중됐다. 이는 공식 Damage 조건에는 들어가지만 Gate B가 요구하는 rear-aspect offensive 조건은 아니다. Gate A가 이를 잡는 것은 조준 기회 coverage인 동시에 high-closing/head-on/overshoot 개입 위험이다.

offensive-tail이라는 scenario 이름과 달리 세 target은 157초 부근 저고도 종료까지 Damage를 내지 못했고 Gate B도 0%였다. scenario 이름만 보고 실제 공격 geometry라고 판단하지 않는다.

## Actual application — frozen H7 policy

H7 seed 1701 bundle, validation mixed, seed 2501~2506에서 각 Gate마다 Pure BT와 paired 실행했다.

| 지표, Hybrid-Pure | Gate A | Gate B | Gate C |
|---|---:|---:|---:|
| Gate active ratio | 86.25% | 96.65% | 86.25% |
| Mean LOS | -0.0187° | -0.0237° | -0.0187° |
| P95 LOS | -0.3465° | -0.2432° | -0.3465° |
| LOS-rate RMS | +0.0027°/s | +0.0005°/s | +0.0027°/s |
| Cone dwell | +0.0472s | +0.0611s | +0.0472s |
| First Damage | +0.0028s | +0.0056s | +0.0028s |
| Damage | +0.00129 | +0.00534 | +0.00129 |
| Hybrid action saturation | 30.16% | 36.00% | 30.16% |

모두 6승, ownship crash 0이지만 target altitude termination 1건이 포함된다. Damage delta는 모든 Gate에서 3개 seed 양수, 3개 seed 음수로 방향이 반복되지 않았다. LOS와 Cone의 작은 평균 변화도 LOS-rate와 median LOS가 함께 좋아지지 않았다. 성능 개선 근거로 사용하지 않는다.

이 근접 validation에서는 offensive condition이 Aim condition을 항상 포함해 Gate C의 실제 non-hybrid trajectory가 Gate A와 모든 seed에서 frame 단위로 같았다. 따라서 이 데이터는 C가 A보다 좋다는 증거가 아니다.

## 불변성·지연

- Pure BT telemetry는 세 Gate 재실행에서 seed별 SHA256이 동일했다.
- Hybrid frame 18,190개에서 final throttle과 BT throttle의 최대 차이는 0이었다.
- Gate OFF action mismatch는 0건이었다.
- clipping은 0이었다.
- inference P95는 Gate A/B/C 각각 약 0.474/0.481/0.509ms였다.

## 잠정 판단

Observation pilot에는 Gate A를 `PROVISIONAL`로 유지한다. 이유는 성능이 이미 우수해서가 아니라 현재 full-fight proxy에서 유효한 opportunity coverage를 보인 유일한 Gate이기 때문이다.

Gate B/C의 현재 threshold는 `CHANGE_HYPOTHESIS`다. 이를 곧바로 완화하면 observation 실험과 gate tuning을 동시에 바꾸게 되므로 지금은 수정하지 않는다.

## 반대 가설과 자기 반박

현재 판단이 틀렸다면 full-fight scenario가 rear-aspect 공격 기회를 만들지 못했기 때문에 B/C가 0%였을 뿐이며, Gate A는 high-closing 정면 사격을 보정해 BT trajectory를 망칠 수 있다. 반대로 current policy가 saturation-aware inward correction으로 포화율을 낮춘 일부 결과는 Aim 개입이 해롭지 않을 가능성을 지지한다.

따라서 Gate A 선택 신뢰도는 중간이며 최종 선택이 아니다. 10D/13D observation pilot 후, 실제 rear-aspect proxy geometry와 독립 policy seed에서 A/B/C를 다시 고정 비교한다.
