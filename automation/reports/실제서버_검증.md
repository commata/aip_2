# 실제 서버 검증

## 상태

`SERVER_BLOCKED`

실제 교전 서버 IP, port, team name, 시나리오와 실행 시간이 제공되지 않아 외부 서버 join/heartbeat/200초 교전을 실행하지 않았다. 서버를 실행하지 않았으므로 서버 검증 완료라고 기록하지 않는다.

## 완료된 로컬 제출 경로 근거

- synthetic packet replay 관측/Gate/action 계약
- localhost UDP 600 frame, 60Hz CMD 600/600
- missing/duplicate/wrong index 0
- P50 1.391ms, P95 2.787ms, P99 3.550ms, MAX 6.349ms
- 166.7ms 초과 0%
- BT frame 600, RL inference 100(action repeat 6)

위 결과는 네트워크 외부 서버 검증을 대체하지 않는다.

## 실제 서버에 필요한 정보

1. server IP
2. port
3. team name
4. 사용할 시나리오
5. 서버 실행 시간
